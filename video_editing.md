# Video Editing Playbook: Cricket & Mythology Reels

A complete summary of the reel-editing work done so far: the workflow, the visual and audio style, the tools, the gotchas, and every project's details. Hand this file to a new chat so it can continue in the same way.

---

## 1. Who / what

- **Creator:** makes Instagram Reels (vertical 9:16) for a Telugu audience, mostly **cricket stats, cricket news and storytelling**, plus mythology.
- **Language:** voiceovers are in **Telugu** or **Tenglish** (Telugu written in English letters), generated by the user in **ElevenLabs** (v3/v4 with `[tone]` audio tags and `<break time="0.4s" />` pauses).
- **The usual flow:**
  1. The user gives a topic or raw stats.
  2. Claude fact-checks the topic and writes the script plus an ElevenLabs voiceover.
  3. Claude lists the images it needs.
  4. The user records the voiceover and sends the images.
  5. Claude edits the video and delivers an MP4.
- **The user's stated preferences:**
  - "Clean, professional editing, no unnecessary text and clutter" (said on the Travishek reel). Keep this as the default.
  - Professional sports-graphics look, like the reference reels (Captain Talks / Kickonomics style: big bold keywords, a clean data look, word-by-word highlighted captions).
  - Wants the **timeline and facts to be accurate**, and is open to script changes.
  - Asked to use **earshot** (https://github.com/Leonxlnx/earshot) for audio and sound effects.
  - Wants short Instagram captions with hashtags after each reel, in **English** by default.

## 3. Environment setup (cloud container)

- **Tools already available:** `ffmpeg` (with libdav1d/AVIF and libjxl/JPEG XL decoders), Python 3.13 with Pillow 12 and numpy.
- **Fonts:** Google Fonts is blocked. Get them from **npm Fontsource** and convert woff2 to TTF with fontTools. Already done, in `video_tools/fonts/`:
  - `Anton.ttf`: big condensed numbers and headlines
  - `Montserrat-Black / ExtraBold / SemiBold.ttf`: labels, captions, letter-spaced small caps
  - `Cinzel-Black / Bold.ttf`: mythology and epic titles
  ```bash
  npm pack @fontsource/anton @fontsource/montserrat @fontsource/cinzel
  pip install fonttools brotli
  # TTFont(woff2).flavor=None; save(.ttf)
  ```
  The **₹ glyph is NOT in Montserrat**, so write "14 CRORE" instead.
- **earshot** (sound-effects bank; it needs no models for `sfx` and `kit`):
  ```bash
  git clone --depth 1 https://github.com/Leonxlnx/earshot
  python3 -m venv es && es/bin/pip install numpy scipy soundfile soxr librosa pyloudnorm scikit-learn pillow matplotlib
  es/bin/pip install --no-deps -e earshot      # skip torch; listening models (~1.1 GB) are not needed
  es/bin/earshot sfx list                      # 252 sounds
  ```
  Python: `from earshot.forge import bank; y, meta = bank.render(id, seed=, dur=, apex=, pitch=)`. It returns 48 kHz stereo audio plus `meta['onset_s']`, `meta['peak_s']` and `meta['checks']['summary']` (the audit).
- **Network:** the session environment allows commons.wikimedia.org, upload.wikimedia.org and speech.platform.bing.com. Wikimedia rate-limits heavily (429 errors with Retry-After up to 600 s), so asking the user for images is faster. Many stats sites are blocked for WebFetch, so WebSearch summaries are what's available.
- **Images the user sends** may be WebP, AVIF or JXL. Convert them with Pillow (WebP, AVIF) or `ffmpeg -i x.jxl x.jpg` (JXL).

## 4. Production workflow (step by step)

1. **Fact-check first.** Use WebSearch, and give a table of ✅ confirmed / ⚠️ fix / ❌ not found. Remove unverifiable claims from scripts and say so. Always end with a **Sources** list of markdown links. Never invent stats. If data is mid-season or conflicting, label it, or ask the user to check iplt20.com or ESPNcricinfo.
2. **Write the script and ElevenLabs voiceover.**
   - Telugu or Tenglish, with `[Tone]` tags and `<break>` pauses.
   - Spell out numbers when needed: "eighteen hundred ninety-two", "twelve point two seven".
   - Suggested settings: Eleven v3, energetic or serious narrator, stability about 40%.
3. **List the images needed** as a numbered table: slot, image, where it's used. Ask for logos the project doesn't have yet.
4. **Analyse the voiceover timing:**
   ```bash
   ffmpeg -i vo.mp3 -af silencedetect=noise=-35dB:d=0.25 -f null - 2>&1 | grep silence_
   ```
   Map the spoken segments to script lines; they usually match one to one. For long segments, run a finer pass (`noise=-30dB:d=0.08-0.1` over a time range) to place numbers on their exact words. Word timing inside a segment is estimated from syllable counts (see `timing.py`). There's no Whisper, because Hugging Face is blocked.
5. **Prepare the images:**
   - Cut out white backgrounds with a flood fill from the edges (players, logos).
   - Remove artefacts by masking and patching (for example, the mouse cursor on the Shani painting).
   - Low-resolution landscape images go in **"framed" mode**: the image full-width over a blurred, darkened copy of itself, with feathered top and bottom edges.
6. **Render with Pillow → raw RGB pipe → ffmpeg x264** at 1080×1920, 30 fps.
   - Always render **preview frames first** (`script.py out.mp4 t1,t2,...`), tile them into a contact sheet and look at it.
   - Fix overlaps and readability, then do the full render (2–7 minutes, in the background).
7. **Audio:** a music bed (synthesised) plus earshot effects placed at measured onsets or peaks.
   - Check that the audit says `clean`, and swap the seed for any take that doesn't (for example, swipe/velvet seeds 3 and 8 have a metallic comb ring).
   - Mix with ducking and loudness normalisation (section 7).
8. **Check:** grab 6 frames from the final MP4 into a strip and check them. Measure loudness (target **-14 LUFS**, true peak around -1.5 dBFS).
9. **Deliver:** send the file, commit `output/*.mp4`, and push. Give a short summary: how the video plays, the sound, and things to check.

## 5. Visual style system

### Common building blocks (see the scripts)
- `timg(text, font, fill, spacing, stroke, glow, shadow)`: a cached text sprite with a soft shadow and optional glow. Use letter spacing for small caps.
- `put(img, sprite, cx, cy, alpha, scale)`: centred composite.
- **Easing:** `eo` (ease-out cubic), `eio` (smoothstep), `back` (overshoot pop); `pr(t, start, dur)` gives progress; `fade(t, a, b)` fades in and out.
- **Ken Burns:** oversample the base image by 1.12–1.18×, then crop a zoom box per frame (`resize(box=...)`).
- **Grain:** 4–6 precomputed noise frames cycled. Vignette and bottom gradient: precomputed multiply arrays.
- **Count-up numbers:** economy figures count **down** from 12.00, because lower is better.

### Style A: energetic stats countdown (IPL death overs, Powerplay Kings)
- Dark navy base with a team-colour radial glow (blends between teams), drifting diagonal light streaks and particles.
- Per rank: a "NO. X" chip, a huge faint rank numeral that slams in, the logo or player photo (photos fade at the bottom; cut-outs have their bottom 22% faded), the name in Anton with the team in Montserrat plus a small logo, and 2–3 **stat cards** (the main card has a team-colour border) that count up **on the spoken word**.
- **#1 reveal:** music breakdown plus drumroll, gold accents, flash, confetti, and a record badge ("IPL RECORD").
- **Transitions:** a diagonal team-colour wipe with a white edge, a flash on reveals, a small screen shake on slams.
- **End:** a leaderboard with bars, then a poll or comment prompt and a pulsing red **+ FOLLOW** pill.
- **Intro:** title stack. **Don't reveal the answers in the intro**; use "?" mystery badges (user feedback).
- **Team colours:** RR (234,26,133)/(60,100,220), DC (30,90,200)/(239,27,35), RCB (213,32,39)/(212,175,55), KKR (120,70,200)/(212,175,55), SRH (242,101,34)/(255,170,60), GT (40,70,150)/(212,175,55, use gold for text, because navy is unreadable).

### Style B: clean cinematic (Travishek), the user's preferred "no clutter" style
- Full-screen photos, slow push-ins, 0.35 s crossfades, grain, vignette.
- Text is limited to: one big Anton number (counting up), a small letter-spaced Montserrat label, one orange accent rule. No captions, no header tag, no particles, no progress bar.
- **Split screen** for head-to-head comparisons, with a dark gradient under each half's stats.
- **Emotional beats:** fade to black and white on "era ended"; fade one person out of a duo photo for "who's next?".

### Style C: documentary investigation (Sandpapergate)
- Muted photos (saturation 0.45, B&W for key moments), warm tint, heavier grain, dark gradients.
- A **timeline bar** at the top (2018 · 2021 · 2026) with red progress and the active year lit.
- **Date cards** typed out in Anton with a red underline; **quote cards** (a big red quote mark plus Anton text plus a small source label); **ban cards** (stacked dark cards with red numbers); a **step tracker** (1st Test → 2nd → 3rd).
- **Procedural inserts** drawn in numpy: a 3D-shaded red ball with seam and stitches, sandpaper rubbing with scuff marks building up, and a rough side vs shiny side diagram.

### Style D: mythology (Hanuman)
- Painterly or public-domain art, saffron colour grade, embers, a Cinzel header ("UNTOLD STORIES of Hanuman").
- Word-by-word captions with the spoken word in saffron, big keyword pop-ups with glow, red tint and shake for the dramatic beats.

### Layout rules learned
- Keep text away from faces. Keywords go in the lower-middle (y ≈ 1100–1500); captions at y ≈ 1400–1670.
- Keep the top 120 px and bottom 250 px light (Instagram UI).
- Low-resolution photos (under 500 px) look soft; tell the user and ask for a bigger one.

## 6. Audio style

- **Energetic:** 128 BPM synthesised beat (kick, clap, hats, bass, chords). Breakdown plus snare drumroll before #1. Effects: a `riser/dark` peaking on the cut, a `whoosh_big/thump` peak 37 ms after the cut, a `cut_hit/kick` on the number slam, `pro_impact/short` plus `reverse_swell/short` on the logo reveal, and `pro_hover_tick/soft` runs (at least 66 ms apart) on count-ups.
- **Clean cinematic:** a soft A minor pad with a melody of earshot `mallet/celesta` notes tuned by `pitch=`. The melody rests under the stats, with a heartbeat sub-pulse. Effects are subtle: `swipe/velvet` on cuts, `cut_hit/sub` on "RELEASED", quiet ticks.
- **Documentary:** a low D drone with a breathing envelope, a ticking clock (faster in the climax section), and a heartbeat. The drone dips on the "final straw" line. Effects: typewriter ticks on dates, `knock/desk` on ban cards, `swipe/paper` strokes for sandpaper rubbing, `impact/deep` on the big reveals.
- **Mythology:** a drone plus bell, booms on keywords.
- **earshot placement rule:** align a whoosh's **peak** just after the cut (+37 ms), a hit's **onset** on the cue, and a riser's **peak** on the cut. Always check that `meta['checks']['summary']` says clean.

## 7. Mix and encode commands

```bash
# voice (mono to stereo) + music ducked under the voice + effects, normalised to -14 LUFS
ffmpeg -y -i video.mp4 -i vo.mp3 -i music.wav -i sfx.wav -filter_complex \
"[1:a]aresample=48000,pan=stereo|c0=c0|c1=c0[v];[v]asplit[v1][v2];\
[2:a]aresample=48000,volume=0.32[m];[m][v2]sidechaincompress=threshold=0.04:ratio=4:attack=20:release=350[md];\
[3:a]volume=0.75[s];[v1][md][s]amix=inputs=3:normalize=0,loudnorm=I=-14:TP=-1.5:LRA=11[a]" \
-map 0:v -map "[a]" -c:v libx264 -preset medium -crf 21 -pix_fmt yuv420p -c:a aac -b:a 192k -ar 48000 \
-shortest -movflags +faststart output/NAME.mp4
```
- Music volume 0.30–0.42 (0.30 for cinematic or documentary); effects 0.75–0.85.
- **Grainy videos get huge** (up to 258 MB). Re-encode with `-vf hqdn3d=1.5:1.5:3:3 -crf 23` (or `-tune grain -crf 24`) to get 50–90 MB.
- Loudness check: `ffmpeg -i out.mp4 -af ebur128=peak=true -f null - 2>&1 | grep -E "I:|Peak:"`.
- Check strip: `ffmpeg -i out.mp4 -vf "select='eq(n\,150)+eq(n\,700)+...',scale=270:480,tile=6x1" -frames:v 1 strip.jpg`.

## 8. Gotchas (bugs already hit)

- `ImageDraw.rectangle(fill=(r,g,b,a))` on an RGBA layer **replaces** pixels instead of blending, so a "faded" bar stays solid after converting to RGB. Composite a separate RGBA image instead (`box()` helper).
- Long foreground ffmpeg runs time out after 2 minutes, so use `run_in_background` and wait with Monitor.
- Don't commit an MP4 while it's still being written. Wait for the render to finish.
- Wikimedia thumbnails must use standard widths (1920 and similar), or they get throttled.
- Hugging Face is blocked, so there's no Whisper. Use silencedetect for timing.
- Some cut-outs are tiny (Kohli was 225 px); flag it to the user.
- Instagram captions: keep them short, with 10–13 hashtags.

```
  powerplay_kings/              # pp.py (player countdown), music.py, sfx.py

```

**Reusing a script:**
- Copy the project folder.
- Put images in `img/` (and logos in `logos/` or `img/`) next to it.
- Put `fonts/` one level up.
- Edit the scene and time tables at the top.
- Run `python3 -I script.py out.mp4 t1,t2` for previews, then `python3 -I script.py video.mp4` for the full render.
- Run the audio scripts with the earshot venv's Python (`es/bin/python audio.py`).

The voiceover MP3s, the user's photos and the work folders were in the session's temporary upload and scratchpad folders and are not in the repo. Ask the user to re-send them if a reel needs re-rendering.
